# AncletoCode 0.1.0 — release estable desktop-only

Primer release **estable** de AncletoCode para escritorio. Incluye todo lo
publicado en las betas anteriores y cierra el trabajo de rendimiento y usage.

**This is a fork of PandaCode** — https://github.com/aicodeking/pandacode

## Destacados

- **Pestaña Uso responsiva:** reporte en segundo plano con caché de 5 minutos,
  refresco manual, progreso por proveedor y ventana siempre operable. El costo de
  red y procesos ya no bloquea la interfaz.
- **Usage por proveedor:** OpenCode reporta costo local y cuotas de OpenCode Go,
  Antigravity consulta `agy -p /usage` y Command Code lee sus límites desde su API
  con la sesión local. Claude muestra un estado explícito, sin cuotas inventadas.
- **Rendimiento general:** comandos IPC que tocan procesos, red o disco corren
  fuera del hilo principal; vistas y terminal se cargan de forma diferida. El
  bundle inicial bajó ~47 % (119,9 KB gzip) y el arranque no descarga KaTeX.
- **Ancleto SDD embebido:** Node y `@ancleto/spec` incluidos, actualización
  administrada desde Ajustes con verificación de integridad y rollback.
- **Sesiones persistentes:** cerrar la ventana hace detach; el host conserva las
  sesiones y las reconcilia al reabrir.
- **Tareas, worktrees y Git local:** board por proyecto, rama y worktree por tarea,
  status, diff, staging, commit, fetch/pull/push, merge y worktrees.
- **Apariencia:** temas, transparencias, fondos y accesibilidad con persistencia
  por proyecto.

## Correcciones incluidas

- Command Code deja de depender de pegar `/usage`: lee créditos y límites de su API.
- OpenCode suma las ventanas de cuota de OpenCode Go al costo local.
- Se corrige la resolución de binarios y el estado de sesión de Command Code.
- Se elimina el diálogo manual de usage y su store.

## Artefactos

| Plataforma | Archivo |
|---|---|
| Linux Debian/Ubuntu | `AncletoCode_0.1.0_amd64.deb` |
| Linux AppImage (Arch/EndeavourOS) | `AncletoCode_0.1.0_amd64.AppImage` |
| Windows instalador | `AncletoCode_0.1.0_x64-setup.exe` / `.msi` |

| Fuente | `AncletoCode-0.1.0-source.tar.gz` |

No se publican AncletoCMD, CLI `acode`, npm ni AUR.

## Instalación

```bash
# Debian/Ubuntu
sudo apt install ./AncletoCode_0.1.0_amd64.deb

# Arch/EndeavourOS
chmod +x AncletoCode_0.1.0_amd64.AppImage
./AncletoCode_0.1.0_amd64.AppImage
# Sin FUSE:
./AncletoCode_0.1.0_amd64.AppImage --appimage-extract-and-run
```

En Windows, instalador o ZIP portable. Verificá `SHA256SUMS` antes de instalar.

## Limitaciones conocidas

- Windows todavía no tiene validación manual de maintainers en este release.
- La actualización firmada de la app está planificada; por ahora solo hay chequeo
  de versión y aviso.
- Review/merge de PRs de GitHub está en curso; el listado de PRs e issues funciona.
- El pack `writer-languages` requiere `npm` del sistema.
- AncletoCMD, CLI `acode`, npm, AUR y macOS quedan fuera de este release.
