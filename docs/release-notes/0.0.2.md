# AncletoCode 0.0.2 — usage y detalles

Release **interno/beta** sobre la base desktop-only de 0.0.1.

**This is a fork of PandaCode** — https://github.com/aicodeking/pandacode

## Novedades

- **Panel Uso de proveedores** inspirado en Orca:
  - OpenCode: costo estimado, tokens y sesiones de los últimos 30 días desde `opencode stats`.
  - Claude, Antigravity y Command Code: estados explícitos cuando el CLI no expone cuotas o no está instalado.
  - Refresco manual, sin prompts ni llamadas de inferencia.
- **GitLab** queda fuera de alcance por ahora; GitHub sigue activo para remoto, PRs e issues vía `gh`.
- Mantiene: UI híbrida PandaCode + Orca, tareas/worktrees, Git local, Ancleto SDD embebido y chequeo de updates.

## Artefactos

| Plataforma | Archivo |
|---|---|
| Linux Debian/Ubuntu | `AncletoCode_0.0.2_amd64.deb` |
| Linux AppImage (Arch/EndeavourOS) | `AncletoCode_0.0.2_amd64.AppImage` |
| Windows instalador | `AncletoCode_0.0.2_x64-setup.exe` / `.msi` |
| Windows portable | `AncletoCode-0.0.2-windows-x64-portable.zip` |
| Fuente | `AncletoCode-0.0.2-source.tar.gz` |
| Integridad | `SHA256SUMS` |

No se publican AncletoCMD, CLI `acode`, npm ni AUR.

## Instalación

```bash
# Debian/Ubuntu
sudo apt install ./AncletoCode_0.0.2_amd64.deb

# Arch/EndeavourOS
chmod +x AncletoCode_0.0.2_amd64.AppImage
./AncletoCode_0.0.2_amd64.AppImage
# Sin FUSE:
./AncletoCode_0.0.2_amd64.AppImage --appimage-extract-and-run
```

En Windows, instalador o ZIP portable. Verificá `SHA256SUMS` antes de instalar.

## Limitaciones

- Windows sigue sin validación manual de maintainers.
- Las cuotas de suscripción de Claude/Antigravity/Command Code todavía no tienen adapter; se muestran estados explícitos en lugar de porcentajes inventados.
- GitLab y otros hosts quedan diferidos.
- Revisión técnica de licencias completada; para un release estable se recomienda revisión legal externa.
