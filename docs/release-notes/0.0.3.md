# AncletoCode 0.0.3 — usage, modelos y CLI discovery

Release **interno/beta** desktop-only.

**This is a fork of PandaCode** — https://github.com/aicodeking/pandacode

## Novedades

- **Usage de Antigravity:** quotas reales vía `agy -p /usage --output-format json`, con ventanas 5h/semanal, porcentaje usado y reset.
- **OpenCode:** tokens y costo local de los últimos 30 días.
- **Claude y Command Code:** estados explícitos (`no instalado`, `sin cuota expuesta`) sin inventar porcentajes.
- **Selector de modelo al crear sesión:** lista modelos de Antigravity, OpenCode y Command Code y pasa `--model`/`-m`; evita quedar atado al modelo/pool default.
- **Detección de CLIs en apps GUI:** busca también en `~/.opencode/bin`, `~/.local/bin`, `~/.npm-global/bin`, `~/.bun/bin` y `~/.cargo/bin`.
- **Node/repomix:** el Node embebido se expone como `node` para que `npx/repomix` no usen el Node del sistema con incompatibilidad de `nghttp2`.
- Mantiene: UI híbrida PandaCode + Orca, tareas/worktrees, Git local, GitHub, Ancleto SDD embebido y chequeo de updates.
- GitLab sigue fuera de alcance.

No se publican AncletoCMD, CLI `acode`, npm ni AUR.

## Instalación

```bash
# Debian/Ubuntu
sudo apt install ./AncletoCode_0.0.3_amd64.deb

# Arch/EndeavourOS
chmod +x AncletoCode_0.0.3_amd64.AppImage
./AncletoCode_0.0.3_amd64.AppImage
# Sin FUSE:
./AncletoCode_0.0.3_amd64.AppImage --appimage-extract-and-run
```

En Windows, instalador o ZIP portable. Verificá `SHA256SUMS` antes de instalar.
