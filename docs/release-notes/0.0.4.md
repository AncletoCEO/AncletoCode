# AncletoCode 0.0.4 — hotfix de OpenCode y modelos

Release **interno/beta** desktop-only. Corrige el alta de sesiones de OpenCode y el selector de modelos de 0.0.3.

**This is a fork of PandaCode** — https://github.com/aicodeking/pandacode

## Correcciones

- El listado de modelos y el lanzamiento de sesiones usan el **`binaryPath` resuelto** de cada driver, no sólo su nombre.
- OpenCode detectado en `~/.opencode/bin` ahora inicia la sesión correctamente, sin dejar una terminal vacía.
- El selector de modelo carga los modelos de OpenCode, Antigravity y Command Code al crear la sesión.
- Se mantiene el pase de `--model`/`-m` al driver seleccionado.
- Se mantiene el usage de Antigravity (`agy -p /usage`), tokens/costo de OpenCode y los estados explícitos de Claude/Command Code.

## Instalación

```bash
# Debian/Ubuntu
sudo apt install ./AncletoCode_0.0.4_amd64.deb

# Arch/EndeavourOS
chmod +x AncletoCode_0.0.4_amd64.AppImage
./AncletoCode_0.0.4_amd64.AppImage
# Sin FUSE:
./AncletoCode_0.0.4_amd64.AppImage --appimage-extract-and-run
```

En Windows, instalador o ZIP portable. Verificá `SHA256SUMS` antes de instalar.

## Limitaciones

- Windows sigue sin validación manual de maintainers.
- Claude y Command Code todavía no tienen adapter de cuota de suscripción.
- GitLab y otros hosts quedan diferidos.
- AncletoCode todavía no se autoactualiza desde Ajustes; 0.0.4 sólo chequea updates.
