# AncletoCode 0.0.8 — modelos y conversación guiada

Release **interno/beta** desktop-only.

**This is a fork of PandaCode** — https://github.com/aicodeking/pandacode

## Correcciones

- **Modelos por `binaryPath`:** OpenCode lista sus 38 modelos aunque el binario no esté en el `PATH` de la app; Command Code lista sus modelos con el Node embebido.
- **Node embebido reparado:** el symlink `node` que apuntaba a una AppImage desmontada se recrea al iniciar. Esto evita el error de Command Code con `nghttp2`.
- **Conversación guiada:** cada turno incluye objetivo compartido, rol A/B, número de turno, turnos restantes y cierre obligatorio en el último.
- **Sin bucle:** se extrae `response` de los sobres JSON de `agy`; no se reenvían `status`, `usage` ni el JSON crudo.
- **Progreso visible:** agente, modelo, número de turno y segundos mientras el one-shot trabaja.
- **Error de permisos headless:** se muestra el motivo y se explica cómo configurar la regla; no se autoaprueban herramientas.
- Se mantienen modelos editables A/B, sesiones con nombre, writer embebido y feedback de discovery.

No se publican AncletoCMD, CLI `acode`, npm ni AUR.

## Instalación

```bash
# Debian/Ubuntu
sudo apt install ./AncletoCode_0.0.8_amd64.deb

# Arch/EndeavourOS
chmod +x AncletoCode_0.0.8_amd64.AppImage
./AncletoCode_0.0.8_amd64.AppImage
# Sin FUSE:
./AncletoCode_0.0.8_amd64.AppImage --appimage-extract-and-run
```

En Windows, instalador o ZIP portable. Verificá `SHA256SUMS` antes de instalar.

## Limitaciones

- Windows sigue sin validación manual de maintainers.
- El pack `writer-languages` requiere `npm` del sistema.
- AncletoCode todavía no se autoactualiza desde Ajustes.
- GitLab y otros hosts quedan diferidos.
