# AncletoCode 0.0.6 — conversación y modelos

Release **interno/beta** desktop-only.

**This is a fork of PandaCode** — https://github.com/aicodeking/pandacode

## Novedades

- **Modelo por agente en conversación:** A y B pueden usar modelos distintos, elegidos desde la pantalla de conversación y persistidos en la conversación.
- **Sesiones con nombre:** al crear una sesión podés ponerle un nombre; se muestra como `Nombre (driver · modelo)`.
- **Primer turno confiable:** la conversación carga turnos existentes y hace polling, evitando que OpenCode termine antes de que el frontend escuche.
- **Selector de modelos OpenCode:** no cachea listas vacías, muestra la cantidad y permite recargar con ↻; se listan los 38 modelos reales.
- Se mantiene writer embebido, pack de lenguajes bajo demanda, feedback de discovery y el resto de 0.0.5.

## Instalación

```bash
# Debian/Ubuntu
sudo apt install ./AncletoCode_0.0.6_amd64.deb

# Arch/EndeavourOS
chmod +x AncletoCode_0.0.6_amd64.AppImage
./AncletoCode_0.0.6_amd64.AppImage
# Sin FUSE:
./AncletoCode_0.0.6_amd64.AppImage --appimage-extract-and-run
```

En Windows, instalador o ZIP portable. Verificá `SHA256SUMS` antes de instalar.

## Limitaciones

- Windows sigue sin validación manual de maintainers.
- El pack `writer-languages` requiere `npm` del sistema.
- AncletoCode todavía no se autoactualiza desde Ajustes.
- GitLab y otros hosts quedan diferidos.
