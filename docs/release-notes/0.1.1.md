# AncletoCode 0.1.1 — arranque, persistencia y Command Code

Release estable de mantenimiento sobre `0.1.0`.

**This is a fork of PandaCode** — https://github.com/aicodeking/pandacode

## Correcciones

- **Command Code:** la conversación parsea el stream NDJSON de eventos
  (`text_delta`, `run_end`, línea final `type: result` con `finalText`) en lugar de
  volcar el JSON crudo. Los deltas se concatenan sin saltos de línea y se ignoran
  thinking, tool calls y métricas.
- **Turnos fantasma:** si la persistencia de un turno falla, la conversación pasa a
  `failed` y el turno no se emite a la interfaz.
- **SQLite:** `busy_timeout=5000`, DDL gateado por `schema_migrations` y un único
  `Store` compartido en la app, sin `database is locked` por contención.

## Rendimiento

- **Arranque sin congelamiento:** `drivers_list` corre en segundo plano, la detección
  se cachea 60 s y cada binario tiene timeout de 3 s. Se elimina el bloqueo de
  10–13 s del primer render cuando `cmd --version` tarda ~3,8 s.
- **Conversación incremental:** se elimina el polling de 1,5 s; la transcripción se
  actualiza por eventos y se reconcilia por foco o tras 10 s de inactividad con
  `conversation_turns_since` (≤32 KB en conversaciones de 800 turnos).
- **IPC:** 17 comandos más pasan a `async` + `spawn_blocking`; la guarda de CI detecta
  I/O transitivo hacia SQLite y procesos.

## Instalación

```bash
# Debian/Ubuntu
sudo apt install ./AncletoCode_0.1.1_amd64.deb

# Arch/EndeavourOS
chmod +x AncletoCode_0.1.1_amd64.AppImage
./AncletoCode_0.1.1_amd64.AppImage
# Sin FUSE:
./AncletoCode_0.1.1_amd64.AppImage --appimage-extract-and-run
```

En Windows, instalador o ZIP portable. Verificá `SHA256SUMS` antes de instalar.

## Limitaciones conocidas

- Windows todavía no tiene validación manual de maintainers en este release.
- La actualización firmada de la app está planificada; por ahora solo hay chequeo
  de versión y aviso.
- Review/merge de PRs de GitHub está en curso; el listado de PRs e issues funciona.
- El pack `writer-languages` requiere `npm` del sistema.
- AncletoCMD, CLI `acode`, npm, AUR y macOS quedan fuera de este release.
