# AncletoCode 0.0.7 — conversación estable

Release **interno/beta** desktop-only.

**This is a fork of PandaCode** — https://github.com/aicodeking/pandacode

## Correcciones

- **Respuestas de `agy` formateadas:** se extrae `response` del sobre JSON y no se reenvían `status`, `usage` ni `conversation_id`. Esto evita que el otro agente vea su propia respuesta serializada y entre en bucle.
- **Turnos activos visibles:** la conversación muestra agente, modelo, número de turno y tiempo transcurrido mientras el one-shot trabaja.
- **OpenCode en conversación:** el one-shot usa el programa resuelto de la sesión, no el nombre suelto `opencode`; se evita `No such file or directory`.
- **Primer turno:** carga inicial de turnos + polling + evento `turn-started`, sin quedarse en “Esperando el primer turno…”.
- **Modelos por conversación:** A y B pueden usar modelos distintos y se persisten.
- **Sesiones con nombre:** `Nombre (driver · modelo)`.
- **Lista de modelos OpenCode:** reintento, refresh y error visible; no cachea listas vacías.
- Se mantiene writer embebido, pack de lenguajes bajo demanda y feedback de discovery de 0.0.6.

## Instalación

```bash
# Debian/Ubuntu
sudo apt install ./AncletoCode_0.0.7_amd64.deb

# Arch/EndeavourOS
chmod +x AncletoCode_0.0.7_amd64.AppImage
./AncletoCode_0.0.7_amd64.AppImage
# Sin FUSE:
./AncletoCode_0.0.7_amd64.AppImage --appimage-extract-and-run
```

En Windows, instalador o ZIP portable. Verificá `SHA256SUMS` antes de instalar.

## Limitaciones

- Windows sigue sin validación manual de maintainers.
- El pack `writer-languages` requiere `npm` del sistema.
- AncletoCode todavía no se autoactualiza desde Ajustes.
- GitLab y otros hosts quedan diferidos.
