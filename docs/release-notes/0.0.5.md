# AncletoCode 0.0.5 — writer, conversación y feedback

Release **interno/beta** desktop-only.

**This is a fork of PandaCode** — https://github.com/aicodeking/pandacode

## Novedades

- **`@ancleto/writer` 0.4.0 embebido** con el Node de la app; ya no requiere instalación npm para el núcleo de writer.
- **Pack de lenguajes bajo demanda:** Ajustes → Writer · pack de lenguajes instala `@ancleto/writer-languages` y lo expone a writer vía `NODE_PATH`.
- **Pantalla dedicada de conversación:** configuración de dos agentes, objetivo, límites, transcript, pausa/reanudar/abortar.
- **Feedback de discovery:** mensaje de progreso, tiempo transcurrido y stdout/stderr/exit code de repomix.
- **Command Code:** el selector muestra nombres legibles (`DeepSeek V4 Flash`) en lugar de descripciones.
- **Conversación con modelo de sesión:** los turnos one-shot reutilizan el modelo/args configurados en la sesión, en lugar de volver al modelo default del CLI.
- Se mantiene el selector de modelos y la detección de CLIs/Node embebido de 0.0.4.

No se publican AncletoCMD, CLI `acode`, npm ni AUR.

## Instalación

```bash
# Debian/Ubuntu
sudo apt install ./AncletoCode_0.0.5_amd64.deb

# Arch/EndeavourOS
chmod +x AncletoCode_0.0.5_amd64.AppImage
./AncletoCode_0.0.5_amd64.AppImage
# Sin FUSE:
./AncletoCode_0.0.5_amd64.AppImage --appimage-extract-and-run
```

En Windows, instalador o ZIP portable. Verificá `SHA256SUMS` antes de instalar.

## Limitaciones

- Windows sigue sin validación manual de maintainers.
- El pack `writer-languages` se instala bajo demanda y actualmente requiere `npm` del sistema.
- Claude y Command Code todavía no tienen adapter de cuota de suscripción.
- AncletoCode todavía no se autoactualiza desde Ajustes.
- GitLab y otros hosts quedan diferidos.
