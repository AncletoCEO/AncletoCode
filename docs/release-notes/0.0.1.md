# AncletoCode 0.0.1 — release desktop-only

Release **interno/beta** para validar la nueva app de escritorio en Linux y
Windows. Reemplaza el release 0.0.1 anterior, que fue retirado para reiniciar el
producto con foco exclusivo en la aplicación.

**This is a fork of PandaCode** — https://github.com/aicodeking/pandacode

## Incluye

- Shell híbrido PandaCode + Orca: navegación por proyectos, tabs/threads,
  inspector, composer, command palette y temas/densidad configurables.
- Sesiones PTY persistentes con detach/attach.
- Tareas por proyecto con board, rama y worktree.
- Git local: status, ramas, diff, staging, commit, fetch, pull, push, merge y
  worktrees.
- Detección de remoto Git y panel GitHub con PRs e issues vía `gh`.
- Ancleto SDD embebido: Node 24.22.1 + `@ancleto/spec` 0.14.0, actualización
  administrada con verificación de integridad y rollback.
- Chequeo de actualizaciones de AncletoCode al iniciar y desde Ajustes.
- Paneles de spec, writer y conversación agente-a-agente integrados.
- Atribución de fork y avisos completos de terceros.

## Instalación

```bash
# Debian/Ubuntu
sudo apt install ./AncletoCode_0.0.1_amd64.deb

# Arch/EndeavourOS
chmod +x AncletoCode_0.0.1_amd64.AppImage
./AncletoCode_0.0.1_amd64.AppImage
# Si no hay FUSE:
./AncletoCode_0.0.1_amd64.AppImage --appimage-extract-and-run
```

En Windows, ejecutar el instalador o descomprimir el ZIP portable y abrir
`ancleto-code-desktop.exe`. El ZIP portable incluye el host de sesiones.

Verificar antes de instalar:

```bash
sha256sum -c SHA256SUMS
```

- La revisión técnica de compatibilidad de licencias está completada
  (`docs/compliance/license-review-0.0.1.md`); para un release estable se
