# AncletoCode 0.0.1 — primer release de prueba

Release **interno/beta** para validar Linux y Windows. No es todavía el release
público estable: la revisión legal de licencias (AGPL-3.0 + atribución de
PandaCode) sigue pendiente.

## Incluye

- App de escritorio Tauri 2 + React: proyectos, árbol y búsqueda, tabs de proyecto
  y agente, sesiones PTY, conversación agente-a-agente, paneles spec/writer,
  apariencia con temas y transparencias, About con atribución.
- CLI `acode` y host `ancleto-code-host`: proyectos, drivers, sesiones,
  attach/detach, `run`, `converse`, passthrough de spec/writer, `doctor`, `ui`.
- AncletoCMD: ventana nativa `winit` + `wgpu`, VT con `alacritty_terminal`,
  tabs/splits, sidebar de proyectos y sesiones, palette, paneles, markdown
  enriquecido, temas, shell integration OSC 133 y restauración de layout.
- Artefactos de escritorio Linux y Windows, más CLI y AncletoCMD standalone.
- npm queda pendiente para un release posterior.

## Plataformas

| Plataforma | Artefactos |
|---|---|
| Linux x86_64 | `.deb`, tarball, AUR `-bin` |
| Windows x64 | NSIS, MSI (si está disponible), ZIP portable |
| npm | pendiente para un release posterior |

## Instalación

```bash
# Debian/Ubuntu
sudo apt install ./AncletoCode_0.0.1_amd64.deb

# Arch/EndeavourOS: extraer ancleto-aur-0.0.1.tar.gz, entrar al paquete
# y ejecutar makepkg -si; o usar el tarball
makepkg -si

# Windows: ejecutar el instalador NSIS/MSI o descomprimir el ZIP portable
# El ZIP portable incluye el host. El instalador puede usar el host del
# ZIP de la CLI o el fallback in-process.

# CLI desde GitHub Release
# Linux: acode-0.0.1-linux-x86_64.tar.gz
# Windows: acode-0.0.1-windows-x64.zip
acode doctor
```

## Limitaciones conocidas

- Revisión legal pendiente (gate 14.12).
- Windows no verificado por los maintainers; se incluye para testers.
- macOS no incluye DMG en 0.0.1.
- AppImage y RPM no incluidos en 0.0.1; Arch usa AUR/tarball.
- El `.deb` debe instalarse en una glibc compatible; los artefactos se construyen
  en Ubuntu 22.04.
- npm queda pendiente para un release posterior.
- El instalador de escritorio no incluye el host de sesiones; usá el ZIP
  portable de la app o el ZIP de la CLI (ambos incluyen el host).
- Ver `docs/windows-testing.md` para el checklist de Windows.

## Verificación

Los assets incluyen `SHA256SUMS`. Reportar problemas en
https://github.com/AncletoCEO/AncletoCode/issues con el template de testing.
