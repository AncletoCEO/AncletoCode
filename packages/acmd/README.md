# @ancleto/code

CLI headless de [AncletoCode](https://github.com/AncletoCEO/AncletoCode) y host local de sesiones.

```bash
npm install -g @ancleto/code
acode doctor
acode --json agents
```

- `acode`: CLI con salida JSON estable y códigos de salida documentados.
- `ancleto-code-host`: host local que es dueño de los PTY y permite detach/attach.
